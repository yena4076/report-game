# 작업실

설치나 빌드 없이 실행되는 HTML/CSS/JS 타이핑 게임입니다. `index.html`을 브라우저로 열어 시작합니다. 인터넷 연결이나 외부 라이브러리, 회원가입이 필요하지 않습니다.

## 🌐 웹사이트 바로가기

[작업실 | Office Playground](https://office-play-theta.vercel.app/)

## 사용 방법
- 메인화면에서 한글 문서의 모드를 누르면 바로 시작합니다.
- 보고서 따라쓰기: 회색 원문을 직접 입력합니다. 한글 조합, 방향키, 선택 영역, Backspace 등 브라우저의 기본 텍스트 편집을 지원합니다. 원문과 정확히 일치하면 다음 보고서로 바로 전환합니다. 오타는 직접 수정합니다.
- Alt+Q: 따라쓰기의 미입력 안내만 즉시 숨기거나 표시합니다. 입력 내용, 선택 영역, 커서, 조합 중인 문자는 건드리지 않습니다.
- 자동 보고서 작성: 글자 키(공백 포함)를 누를 때마다 준비된 원문 한 글자를 출력합니다. 줄바꿈도 원문 순서대로 출력됩니다. Backspace는 마지막 한 글자를 지웁니다. 입력 위치는 문서 끝으로 유지됩니다. 완성된 보고서는 남겨두고 다음 보고서를 이어 씁니다.
- 오른쪽 위 X: 확인창 없이 메인으로 돌아가며 입력을 초기화합니다.
- 상단 메뉴와 서식 표시줄은 장식입니다. 다른 프로그램 카드는 준비 중입니다.

## GitHub Pages 배포
1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `style.css`, `app.js`, `.nojekyll`을 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
4. `main` 브랜치와 `/ (root)` 폴더를 선택하고 Save를 누릅니다.
5. 배포가 끝나면 Pages에 표시된 주소로 접속합니다.

하위 경로에서도 동작하도록 모든 파일 경로를 상대 경로로 지정했습니다. 서버 기능이나 비밀 키는 없습니다. 실제 GitHub 배포는 이 파일에 포함되지 않습니다.

## 확장
`app.js`의 `PROGRAMS`가 카드와 모드를 정의합니다. 현재는 document의 두 모드만 구현되어 있습니다. 새 프로그램을 추가할 때는 실행 로직도 구현한 다음 modes를 연결하세요. `REPORTS`에 제목과 본문을 추가하면 두 모드에서 순환 사용합니다.

모든 보고서와 그래픽 UI는 이 프로젝트를 위해 직접 작성했습니다. 실제 한글 프로그램 또는 다른 브랜드와 제휴하지 않으며, 브랜드 로고·스크린샷·폰트를 포함하지 않습니다. 시스템에 설치된 글꼴을 사용합니다.

데스크톱 키보드 사용을 권장합니다. 모바일에는 Alt 키가 없으므로 Alt+Q는 하드웨어 키보드가 필요합니다. 브라우저/운영체제가 단축키를 먼저 처리하는 환경에서는 Alt+Q가 전달되지 않을 수 있습니다.
